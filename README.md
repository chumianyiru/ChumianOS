# ChumianOS

基于 Flutter 开发的粉色系定制 Android 系统应用，包含桌面启动器和开机引导两个独立 APK。

## 项目结构

- `chumian_launcher/` - ChumianOS 桌面启动器 + 系统设置
- `chumian_welcome/` - ChumianOS 开机引导

## 功能特性

### 桌面启动器
- 全屏手势导航，替代系统三大金刚键
- 所有桌面图标强制圆形显示
- 粉色渐变壁纸风格
- 内置 30+ 桌面小组件
- 长按桌面进入编辑模式
- 10 套桌面图标主题
- 自制粉色通知栏
- 内置系统设置模块
- Material 3 (Material You) 设计

### 开机引导
- 系统启动后第一个弹出
- 4 步激活引导流程
- 点击激活后自动完成配置
- Material 3 粉色设计

## 构建

通过 GitHub Actions 自动构建 APK。
